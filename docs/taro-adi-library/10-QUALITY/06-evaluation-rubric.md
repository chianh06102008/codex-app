# Weighted UI evaluation rubric (Taro-created, not publisher official)

Score each dimension 0–4 with explicit evidence. A number without a linked screen or test is not meaningful.

| Dimension | Weight | 0 | 2 | 4 |
|---|---:|---|---|---|
| Core task completion | 25% | Main flow fails | Works with friction | Reliable and direct |
| Information architecture | 15% | Important actions hidden | Mostly navigable | Clear, predictable and scalable |
| Accessibility and inclusivity | 20% | Blocking barriers | Some issues | Key tested paths accessible |
| Visual craft | 15% | Unsystematic | Generally consistent | Deliberate hierarchy/tokens/detail |
| States and feedback | 15% | Missing/incorrect | Partial | Distinct and tested |
| Responsive and content robustness | 10% | Breaks | Acceptable in common cases | Robust under long/empty/zoom states |

**Compute:** sum `(score / 4) × weight`. This rubric measures Taro review judgment, not WCAG or ISO certification. Any blocking functional/accessibility issue prevents an overall “production-ready” label regardless of weighted score.
