# Accessibility gate — original functional review

> Independent checklist; refer to the official WCAG 2.2 Recommendation for actual criterion text: https://www.w3.org/TR/WCAG22/. The library does not reprint it or confer WCAG conformance.

## Blocking checks

- [ ] Every essential action works with supported keyboard and input methods, without a pointer-only assumption.
- [ ] Focus is visible and progresses through controls in logical order.
- [ ] Open dialogs/panels have correct entry, exit and focus restoration.
- [ ] Controls have accessible names and appropriate roles and states.
- [ ] Visible instructions and field errors are associated with their input.
- [ ] Important information is not conveyed through color alone.
- [ ] Text and key controls retain sufficient perceptibility under applicable contrast policy.
- [ ] Content is not clipped or inaccessible at the supported zoom, text enlargement and viewport sizes.
- [ ] Motion can be reduced when a user preference requests it.
- [ ] Error messages distinguish the condition and possible recovery.

## Review record

Include viewport and zoom, user interaction sequence, observed result, actual computed styles when necessary, expected state and source of test evidence. For legal conformance, run an actual standards-based audit rather than declaring success on this checklist alone.
