# Source rights and redistribution policy

**Review date:** 2026-11-14. **Status:** practical risk assessment, not legal advice. Original ADI prose is written for this package; source publications, software, trademarks, brand assets and documentation remain subject to their owners' terms.

## Key distinction

- **Reference**: a URL, edition, title or publicly known concept, without republishing source text.
- **Original operational rule**: an independently written implementation check, never advertised as verbatim publisher advice.
- **Publisher-source text**: original words, illustrations, icons, table values, screenshots, Figma assets and proprietary tokens. **None are bundled.**
- **Software**: repositories and individual packages with their own licenses; license on code is not automatically a license for a distinct documentation website.

## Mandatory handling rules for Taro

1. Never classify **viewable online** as **redistributable** or **AI-ingestable**.
2. Never classify a publisher's documentation website as open source merely because a corresponding *software library* has MIT/Apache code.
3. Do not crawl, download, ingest, transform or embed restricted publisher text on the strength of this package.
4. Keep source version, retrieval date, applicable license and attribution for any separately user-provided authorized material.
5. If license is unclear, store the URL and Taro's independent review guidance, not the publisher content.
6. Do not claim official affiliation, endorsement or full publisher conformance.
7. Treat future source updates as changes requiring revalidation rather than silently replacing old rules.

## Incorporating separately authorized material

A project owner may obtain express permission/license for specific publication text. Such material must be reviewed for AI use, redistribution, retention, derivative works, and target audience restrictions *before* any ingestion; do not assume purchased access permits AI processing. Maintain these materials outside this portable reference ZIP until legal review. No licensed ISO files were provided or processed here.
