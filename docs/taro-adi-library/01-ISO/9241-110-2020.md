## Original operational rules

1. **ADI-ISO-9241_110_2020-H01** — For every user action, define an observable initial state, pending state and completion state.
2. **ADI-ISO-9241_110_2020-H02** — Give users a reliable escape route for optional operations, and an undo route where technically feasible.
3. **ADI-ISO-9241_110_2020-H03** — Keep labels and outcomes aligned with the user’s mental model of the task.
4. **ADI-ISO-9241_110_2020-H04** — Detect and correct errors close to the relevant control instead of relying only on global alerts.
5. **ADI-ISO-9241_110_2020-H05** — Minimize unnecessary steps for repeated expert work without hiding critical safeguards.
6. **ADI-ISO-9241_110_2020-H06** — Keep permissions and automated decisions explainable enough for users to anticipate consequences.
7. **ADI-ISO-9241_110_2020-H07** — Provide progressive, context-sensitive help for unfamiliar workflows.
8. **ADI-ISO-9241_110_2020-H08** — Ensure interaction behavior is predictable across equivalent controls and flows.

## What would fail the companion review

- Status of a requested action changes without feedback
- UI offers Cancel but cancellation is not honored
- Error only appears after losing form work
- Same command behaves differently in sibling views
