# Example — a request mentioning ISO 9241

## Appropriate answer from Taro

- Reference the applicable published standard by edition and title.
- State that this library contains independent heuristics, not licensed ISO clauses.
- Use the independent heuristics to improve interfaces and identify test scenarios.
- For required **ISO conformity**, ask for an authorized human review under the applicable standard and do not claim compliance based on this package.
- Do not send purchased ISO PDFs or extracted passage content into the agent without express rights for AI processing.

## Forbidden outputs

- “This passes ISO 9241-110 §5.4” without the authorized publication and a valid assessment method.
- A reconstructed clause library presented as the actual standard.
- A generated “ISO certificate” from a heuristic score.
