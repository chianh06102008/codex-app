## Minimum usable contract

1. Every chart has a measurement, unit, time range and interpretation.
2. Filters show selected values and update chart/table outputs predictably.
3. Empty/missing-source data does not silently become zero.
4. Direct chart labels or keyboard-compatible data tables permit interpretation beyond color.
5. At narrower widths, summary metrics reflow but the data relationships remain intact.
6. Dense tables offer sorting and sufficiently clear row identities.

The Carbon chapter is an implementation inspiration, not a claim that a non-Carbon chart is compliant with Carbon.
